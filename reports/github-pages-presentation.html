تقرير تفعيل GitHub Pages

تحويل فهرس MyUseGuids إلى موقع ويب مباشر قابل للتصفح.

المستودع: alharbikh/MyUseGuids

المشكلة الحالية

عند فتح index.html من GitHub يظهر مصدر HTML، وليس صفحة ويب بتصميمها الكامل.

الوضع الحاليGitHub يعرض الكود داخل المستودع.
الحاجةرابط مباشر يفتح الفهرس من الجوال والكمبيوتر.
الحلتفعيل GitHub Pages من main وroot.

الإعداد المطلوب

SourceDeploy from a branch
Branchmain
Folder/(root)

هذا مناسب لأن index.html موجود في جذر المستودع.

خطوات التفعيل

افتح مستودع alharbikh/MyUseGuids.
ادخل إلى Settings.
افتح Pages من القائمة الجانبية.
اختر Deploy from a branch.
اختر main ثم /(root) ثم Save.
انتظر النشر ثم افتح Visit site.

الرابط المتوقع

بعد نجاح النشر يصبح الفهرس متاحًا كموقع مباشر:

https://alharbikh.github.io/MyUseGuids/

الروابط النسبية بين الأدلة ستعمل تلقائيًا داخل GitHub Pages أو عند نقل الملفات لاستضافة أخرى.
