1. المنصات والمواقع والإضافات المماثلة في التعليم السعودي

منصة ويب متخصصة التعليم العام
منصة تواصل (2wasl)

منظومة رقمية رائدة تقدم نماذج تفاعلية واستمارات خطط التحسين المدرسي والتطوير، مع توفير أدوات ربط إلكترونية للمدارس وإدارة النماذج الإدارية وتصديرها.

أبرز الخدمات والنماذج:
  • نماذج خطط التحسين والتطوير المدرسي التفاعلية.
  • استمارات متابعة مؤشرات الأداء والانضباط المدرسي.
  • سجلات الشواهد وتوثيق الفعاليات المدرسية.
حلول إدارية وميدانية شؤون المعلمين والطلاب
أنظمة إدارة ومساندة الوكيل الميداني

برمجيات وحلول مصممة لأتمتة المهام اليومية لوكيل الشؤون التعليمية والمدرسية وشؤون الطلاب وفق الدليل التنظيمي والإجرائي لوزارة التعليم.

أبرز الخدمات والنماذج:
  • أتمتة جداول حصص الانتظار وتوزيع الحصص الشاغرة.
  • سجلات الإشراف والمناوبة اليومية عند البوابات والفسح.
  • إدارة سجلات دوام الموظفين والتأخر والانصراف.
إضافات متصفح (Extensions) نظام نور ومنصة مدرستي
إضافات المتصفح لنظام نور ومدرستي

أدوات مساعدة لمتصفحات Chrome و Edge تعمل على تسريع رصد الغياب الجماعي، سحب التقارير، وتوليد كشوفات الحضور تلقائياً بنقرة زر.

أبرز الخدمات والنماذج:
  • الرصد التلقائي للغياب والتأخر اليومي في نظام نور.
  • استخراج مسيرات الدوام وسجلات الطلاب بتنسيق Excel/PDF.
  • توليد رسائل وإشعارات الغياب الفورية عبر تطبيق WhatsApp.

2. مجالات الاستخدام والنماذج المؤهلة للأتمتة والدمج

في ماذا يمكننا استخدام هذه المنظومات؟
✓
الأرشفة السحابية وتقليل الهدر الورقي: تحويل السجلات الورقية الثقيلة إلى نماذج رقمية تفاعلية تحفظ محلياً أو سحابياً مع سهولة الرجوع إليها.
✓
سرعة إعداد وطباعة التقارير الرسمية: توليد محاضر الانضباط، إشعارات أولياء الأمور، وجداول الانتظار اليومية في ثوانٍ معدودة.
✓
الامتثال للوائح وزارة التعليم: ضمان تطبيق قواعد السلوك والمواظبة المحدثة والدليل الإجرائي المعتمد بصورة نظامية ودقيقة.

3. المواصفات الطباعية الرسمية للنماذج (أنواع وأحجام الخطوط)

لضمان خروج النماذج والقوالب بنفس الدقة والتصميم الإداري المعتمد في وزارة التعليم، يجب تطبيق معايير الخطوط والمقاسات التالية:

العنصر داخل النموذج نوع الخط المعتمد الحجم (Font Size) الوزن (Weight) الاستخدام الموصى به
الترويسة وعنوان النموذج Cairo أو Tajawal 16pt - 18pt (22px - 24px) Bold (700 / 800) اسم المدرسة، رقم النموذج الرسمي (مثل نموذج 18)
عناوين الجداول والأقسام Cairo 12pt - 14pt (16px - 18px) Semi-Bold (600) رؤوس الأعمدة في جداول الدوام والانتظار والمناوبة
بيانات الحقول والنصوص Tajawal أو Cairo 10pt - 11pt (13px - 14px) Regular (400) أسماء المعلمين، السجلات المدنية، الإفادات، التوجيهات
الملاحظات والهوامش السفلية Tajawal 8pt - 9pt (11px - 12px) Regular (400) / Light التعليمات الإجرائية، تواريخ الرصد، أرقام الصفحات
خانات التواقيع والاعتماد Cairo 11pt (14px) Bold (700) توقيع الموظف، توقيع الوكيل، وختم مدير المدرسة

4. قواعد التنسيق البرمجي (CSS Standards) للطباعة والقوالب

يمكنك نسخ كود CSS التالي وتطبيقه على أي قالب ترغب في دمج النماذج المجردة معه لضمان التوافق التام مع مقاسات الطباعة (A4):

/* معايير ضبط الخطوط وقوالب الطباعة الرسمية للنماذج */
@media print {
  @page {
    size: A4 portrait;
    margin: 15mm 12mm 15mm 12mm;
  }
  body {
    font-family: 'Tajawal', 'Cairo', sans-serif !important;
    font-size: 10pt;
    color: #000000 !important;
    background: #ffffff !important;
  }
  .form-title-bar h5 {
    font-size: 14pt !important;
    font-weight: 700;
  }
  .table {
    border-color: #000000 !important;
    font-size: 9.5pt !important;
  }
  .table th {
    background-color: #f2f2f2 !important;
    color: #000 !important;
  }
  .no-print {
    display: none !important;
  }
}
