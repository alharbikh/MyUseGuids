# SmartProDigital Guides

مستودع مقترح للأدلة التشغيلية الخاصة بمشروع SmartProDigital.

## الأدلة الحالية

- `linear-github-ai-guide.html`
  - شرح Linear وأهم النوافذ والمصطلحات والحالات.
  - تطبيق عملي على SmartProDigital.
  - نموذج تكامل Linear + GitHub + ChatGPT/Codex.
  - أوامر تشغيل ومراجعة جاهزة.
  - تصميم RTL متجاوب بخط Cairo.

## الاستخدام

افتح ملف HTML مباشرة في المتصفح على الكمبيوتر أو الجوال.

## سياسة المستودع

هذا المستودع مخصص للأدلة والتوثيق التشغيلي فقط، ولا يحتوي على كود المنتج أو الأسرار أو بيانات البيئات.
