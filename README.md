# MyUseGuids — الأدلة التشغيلية

مستودع مركزي للأدلة التشغيلية والمرجعية التي نستخدمها في SmartProDigital والأعمال المرتبطة به.

## نقطة البداية

افتح `index.html` لعرض فهرس الأدلة. جميع روابط الفهرس **نسبية** حتى يعمل المجلد عند نقله كاملًا إلى أي استضافة أو موقع آخر.

## الأدلة الحالية

- `git-commands-guide.html` — دليل أوامر Git بالعربية.
- `linear-github-ai-guide.html` — دليل Linear وتكامل SmartProDigital مع GitHub وChatGPT/Codex.
- `hudoori_business_payments_and_stores_guide_genspark.html` — دليل حضوري سمارت برو: التأسيس والمدفوعات والمتاجر.
- `دليل إعداد بريد Supabase Auth ورموز OTP.html` — إعداد بريد Supabase Auth ورموز OTP.
- `دليل استخدام ميسر.html` — دليل استخدام بوابة ميسر للدفع الإلكتروني.

## قاعدة إلزامية عند إضافة أي دليل جديد

عند إضافة أو رفع أي دليل HTML جديد إلى المستودع يجب تنفيذ الآتي **في نفس التغيير**:

1. إضافة الدليل إلى `index.html` بعنوان واضح ووصف مختصر.
2. استخدام رابط **نسبي** للدليل، مثل `./my-guide.html`، وعدم استخدام رابط GitHub مطلق داخل الفهرس.
3. إضافة شريط تنقل ثابت أعلى الدليل يحتوي على رابط نسبي إلى `./index.html` بعنوان مثل **فهرس الأدلة** أو **الرئيسية**.
4. تحديث قسم **الأدلة الحالية** في هذا `README.md`.
5. التأكد من أن الصفحة RTL ومتجاوبة مع الجوال قدر الإمكان، ويفضل استخدام خط Cairo للأدلة العربية.
6. عدم إضافة أسرار أو مفاتيح API أو بيانات بيئات حساسة إلى أي دليل.

> قاعدة الصيانة: **إضافة دليل بدون تحديث `index.html` تعتبر إضافة غير مكتملة.**

## قابلية النقل

يفضل إبقاء `index.html` وجميع الأدلة في نفس المجلد الجذري ما لم نقرر لاحقًا تنظيمها في مجلدات. عند نقل المستودع أو نسخه إلى استضافة أخرى، انقل المجلد كاملًا للحفاظ على الروابط النسبية.

## سياسة المستودع

هذا المستودع مخصص للأدلة والتوثيق التشغيلي فقط، ولا يحتوي على كود المنتج الأساسي أو الأسرار أو بيانات البيئات.
