MyUseGuids — GitHub Pages⌂ فهرس الأدلة

دليل تفعيل GitHub Pages لمستودع MyUseGuids

تحويل فهرس الأدلة من ملف HTML داخل GitHub إلى موقع ويب مباشر يمكن فتحه من الكمبيوتر والجوال.

النتيجة المطلوبة

بعد التفعيل سيصبح index.html الصفحة الرئيسية للموقع، وستعمل الروابط النسبية بين الأدلة تلقائيًا.

العنوان المتوقع لهذا المستودع هو: https://alharbikh.github.io/MyUseGuids/

الخطوات

1
افتح المستودع MyUseGuids.
من GitHub افتح مستودع alharbikh/MyUseGuids.
2
افتح Settings.
من شريط المستودع اضغط Settings. إذا لم تظهر، افتح قائمة التبويبات الإضافية ثم Settings.
3
افتح Pages.
من القائمة الجانبية، ضمن Code and automation اختر Pages.
4
حدد مصدر النشر.
في Build and deployment اجعل Source = Deploy from a branch.
5
اختر الفرع والمجلد.
Branch = main
Folder = /(root)
ثم اضغط Save.
6
انتظر النشر.
GitHub سيبني الموقع وينشره. قد يستغرق ظهور التغييرات عدة دقائق، وتذكر وثائق GitHub أنه قد يستغرق حتى نحو 10 دقائق بعد الدفع.
7
افتح الموقع.
ارجع إلى Settings → Pages. عند نجاح النشر سيظهر Visit site. اضغطه لفتح فهرس الأدلة كموقع حقيقي.

الإعداد المناسب لـMyUseGuids

الخيارالقيمة
SourceDeploy from a branch
Branchmain
Folder/(root)
Entry fileindex.html

هذا هو أبسط إعداد لأن ملفات الأدلة وملف index.html موجودة مباشرة في جذر المستودع، ولا نحتاج إلى build system أو GitHub Actions خاص.

ماذا يحدث بعد التفعيل؟

عند تحديث أي دليل أو إضافة دليل جديد إلى main، ينشر GitHub Pages التغييرات من مصدر النشر المحدد.

دليل جديد → رفع HTML → تحديث index.html → Commit إلى main → GitHub Pages ينشر النسخة الجديدة.

بما أن الروابط في الفهرس والأدلة نسبية، فستعمل داخل GitHub Pages وكذلك عند نقل مجموعة الملفات إلى استضافة أخرى.

إذا ظهر 404

  1. تأكد أن Pages مضبوط على main و/(root).
  2. تأكد أن index.html موجود في جذر الفرع.
  3. انتظر عدة دقائق بعد أول تفعيل.
  4. راجع Settings → Pages وحالة النشر.
  5. راجع Actions إذا أظهر GitHub فشل عملية Pages.
GitHub Pages موقع عام على الويب. لا تضع في ملفات الأدلة أسرارًا أو API keys أو بيانات حساسة.
